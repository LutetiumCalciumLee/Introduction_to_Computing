# Introduction to Computers
This repository contains my notes on Introduction to Computers, studied as part of the High-Tech Program in the Department of AI Software.


## [**Chapter 1 – AI in Our Society**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.01)  
- **Metaverse & Virtual Worlds**: Fusion of AR, VR, MR, XR in daily life; ASF categories (AR, Lifelogging, Mirror, Virtual).  
- **AI in Daily Life**: From Turing to deep learning; use in AlphaGo, STT/TTS, chatbots, autonomous driving.  
- **Internet Contents**: Smart revolution after WWW and smartphones; rise of OTT, UCC, SNS with AI-based recommendation.  
- **4th Industrial Revolution**: Smart society built on AI, IoT, big data for decision-making and automation.

## [**Chapter 2 – Computer Overview**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.02)  
- **Definition**: Processing, storing, input, output using binary.  
- **Hardware**: CPU (ALU + control unit), memory (RAM), I/O devices.  
- **Software**: OS and applications.  
- **History**: From calculators to modern generations.  
- **Types**: PC, workstations, mainframes, kiosks, etc.

## [**Chapter 3 – Information Representation**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.03)  
- **Data Format**: Binary (0s and 1s).  
- **Number Systems**: Binary, octal, hex; conversions.  
- **Negative Numbers**: 2’s complement method.  
- **Units**: Bit, byte, KB to TB.  
- **Floating Point**: 32/64-bit structure.  
- **Encoding**: ASCII, Unicode.  
- **Logic Operations**: AND, OR, NOT, Boolean algebra.  
- **Arithmetic**: Addition, subtraction using 2’s complement.  
- **Circuit Design**: Truth table to gates.

## [**Chapter 4 – Computer Architecture**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.04) 
- **Von Neumann Model**: Shared memory for data & code.  
- **Instruction Format**: Opcode + operand.  
- **Memory System**: RAM, ROM, BIOS, address-based access.  
- **Cache & Buffer**: Speed bridge.  
- **Storage**: HDD, SSD, USB.  
- **Memory Hierarchy**: Register → cache → RAM → HDD.  
- **CPU**: ALU, control unit, register.  
- **Cycle**: Fetch → decode → execute.  
- **Performance**: Clock, bus, Moore’s law, RISC vs CISC.

## [**Chapter 5 – Operating Systems**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.05)  
- **Definition**: Manages hardware, software, and user interface.  
- **Functions**: Process, memory, file, device management.  
- **Interface Types**: CLI vs GUI.  
- **Resource Management**: Task scheduling, memory allocation.  
- **Types**: Batch, time-sharing, multiprocessing, real-time, distributed.  
- **History**: MS-DOS → Windows → Linux/Unix.  
- **Windows Tips**: Virtual desktops, Explorer shortcuts, folder options.

## [**Chapter 6 – AI & Deep Learning**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.06)
- **AI Overview**: Mimicking intelligence.  
- **Machine & Deep Learning**: Data-driven learning, neural nets.  
- **Milestones**: AI winters → resurgence.  
- **Neural Networks**: MLP and perceptrons.  
- **Applications**: NLP, diagnosis, art, autonomous driving.  
- **Ethics**: Privacy, safety, responsibility.

## [**Chapter 7 – Computational Thinking**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.07)  
- **Definition**: General problem-solving framework.  
- **Components**: Data handling, decomposition, abstraction, patterning.  
- **Significance**: Enhances logic, creativity, communication.  
- **Techniques**: Divide & conquer, top-down design.  
- **Tools**: Scratch, Entry, Python, Blockly.

## [**Chapter 8 – Programming Languages**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.08)    
- **Concepts**: Low-level vs high-level.  
- **Generations**: FORTRAN → BASIC → Python, R, Go.  
- **Development Tools**: IDEs like VS, GoLand.  
- **Execution**: Compile → link → debug.  
- **Languages**: C, Java, Swift, Kotlin, etc.  
- **OOP**: Abstraction, inheritance, encapsulation, polymorphism.

## [**Chapter 9 – Databases**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.09)  
- **Concepts**: Structured, minimized redundancy.  
- **DBMS**: Interface between data & users.  
- **Structure**: Field → record → file → database.  
- **Abstraction**: Physical, logical, view layers.  
- **Models**: Hierarchical, network, relational.  
- **SQL Practice**: Query, insert, update.  
- **Types**: MySQL, Oracle, SQLite.  
- **Data Mining/NoSQL**: Big data, MongoDB.

## [**Chapter 10 – Networks & WWW**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.10)  
- **Concepts**: TCP/IP, LAN/WAN, sender-receiver.  
- **Devices**: Modem, router, hub, NIC.  
- **Types**: LAN, MAN, WAN.  
- **Settings**: IP, DNS, tracert.  
- **Internet History**: ARPANET → IPv6.  
- **Web Tech**: HTML5, CSS, JS.  
- **Paradigms**: Web 1.0 → 2.0 → 3.0.

## [**Chapter 11 – 4IR & Advanced Tech**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.11)    
- **Revolutions**: Steam → electricity → digital → smart.  
- **Core Tech**: AI, IoT, cloud, robots, blockchain.  
- **Hyperconnectivity**: All things networked.  
- **Cloud/Mobile**: iOS, Android, SaaS, etc.  
- **Robots**: Humanoids, wearables.  
- **Big Data**: 3Vs + AI.  
- **Blockchain**: Transparent, secure records.  
- **Future Skills**: CT, creativity, collaboration.  
- **Education**: Nanodegree, industry training.

## [**Chapter 12 – Multimedia**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.12)  
- **Overview**: Audio, image, video, text.  
- **Formats**: MP3, JPEG, MPEG, Unicode.  
- **System**: Hardware + software.  
- **Compression**: Lossless (Huffman), lossy (JPEG).  
- **Applications**: VOD, telemedicine, UHD.  
- **Security**: DRM, watermarking, fingerprinting.

## [**Chapter 13 – Information Security**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.13)  
- **Concepts**: Confidentiality, integrity, availability.  
- **Threats**: Viruses, phishing, hacking, DDoS.  
- **Countermeasures**: Antivirus, strong passwords, backups.  
- **Encryption**: RSA, AES, public/private keys.  
- **Internet Security**: SSL, firewalls, secure email.  
- **Ethics**: Respect, responsibility, privacy protection.

# 컴퓨터 개론
이 레포지토리에는 인공지능소프트웨어과 하이테크 과정에서 학습한 컴퓨터 개론 내용을 정리하여 업로드했습니다.


## [**1장 – 인공지능과 함께하는 우리사회**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.01)

* **가상세계와 메타버스**: AR, VR, MR, XR 기술을 기반으로 한 현실-가상 융합 공간. ASF 기준으로 4가지 유형(AR, 라이프로깅, 거울세계, 가상세계) 분류.
* **인공지능과 삶의 변화**: 튜링 → 딥러닝 발전. AlphaGo, STT, TTS, 챗봇, 자율주행 등 AI 기술 활용 사례.
* **인터넷 콘텐츠 서비스**: WWW, 스마트폰 이후 OTT, UCC, SNS 발전. 추천 시스템 등 AI 콘텐츠 기술 적용.
* **제4차 산업혁명 시대**: AI, IoT, 빅데이터 융합 사회. 데이터 기반 의사결정, 스마트 산업 실현.


## [**2장 – 컴퓨터 개요**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.02)

* **컴퓨터란**: 처리, 저장, 입력, 출력 수행. 0과 1의 디지털 정보 처리.
* **하드웨어 요소**: CPU(ALU+제어장치), 기억장치(RAM, 보조), 입력/출력 장치.
* **소프트웨어 요소**: 시스템(운영체제), 응용(앱 등).
* **기원과 발전**: 계산기 → 전자식 컴퓨터 → 현대 발전세대.
* **종류**: PC, 워크스테이션, 메인프레임, 슈퍼컴퓨터, 키오스크 등.


## [**3장 – 정보의 표현**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.03)

* **자료 표현**: 0과 1로 표현. 이진법 기반.
* **진수 표현**: 2진수, 8진수, 16진수, 변환 방법.
* **음수 표현**: 2의 보수 방식 사용.
* **저장 단위**: 비트, 바이트, KB~TB 단위.
* **부동소수점 수**: 실수 표현, 단정도/배정도.
* **문자 인코딩**: ASCII, Unicode.
* **논리 연산**: AND, OR, NOT, 진리표, 부울 대수.
* **산술 연산**: 덧셈, 2의 보수 뺄셈, 오버플로우.
* **논리 회로 설계**: 진리표 기반 회로 생성.


## [**4장 – 컴퓨터 구조**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.04)

* **폰 노이만 구조**: 명령어+데이터 동일 기억장치. 인출-해독-실행.
* **명령어 구조**: Opcode + Operand (예: ADD, LOAD).
* **기억장치**: RAM, ROM, BIOS 등 주소 기반 접근.
* **캐시/버퍼**: CPU-메모리 속도 차 보완.
* **보조기억장치**: HDD, SSD, USB.
* **기억 계층**: 레지스터→캐시→RAM→보조장치.
* **CPU 구성**: ALU, 제어장치, 레지스터.
* **명령어 처리**: Fetch → Decode → Execute.
* **성능 요소**: 클럭, 버스 폭, 병렬처리, 무어의 법칙, CISC vs RISC.


## [**5장 – 운영체제와 활용**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.05)

* **운영체제 개요**: 시스템 자원 관리 및 사용자 인터페이스 제공.
* **주요 기능**: 프로세스/메모리/파일/장치 관리.
* **인터페이스 방식**: CLI(텍스트) vs GUI(그래픽).
* **자원 관리**: 프로세스 상태 전환, 메모리 적재, 드라이버 기반 I/O 관리.
* **운영체제 유형**: 일괄처리, 시분할, 다중처리, 실시간, 분산처리 등.
* **발전 과정**: MS-DOS → Windows → 리눅스, 유닉스 등.
* **윈도우 활용**: 가상 데스크톱, 파일 탐색기 바로가기, 폴더 옵션 설정.


## [**6장 – 인공지능과 딥러닝**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.06)

* **AI 개요**: 인간 지능의 컴퓨터 구현. 튜링테스트, 퍼셉트론.
* **머신러닝/딥러닝**: 데이터 기반 학습. 다층 신경망 사용.
* **역사적 이정표**: AI 겨울 극복, 역전파, 2010년대 딥러닝 도약.
* **신경망**: MLP 구조. 퍼셉트론으로 시작.
* **응용 분야**: 의료, 언어처리, 추천, 자율주행, 창작 등.
* **윤리 고려**: 안전성, 프라이버시, 사회적 영향.


## [**7장 – 컴퓨팅사고력과 문제해결**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.07)

* **컴퓨팅 사고력 개요**: 복잡한 문제를 논리적으로 해결.
* **핵심 요소**: 자료 수집, 분석, 문제분해, 추상화, 알고리즘 설계.
* **중요성**: 프로그래밍 능력 이상, 창의·논리·협업 역량 강화.
* **문제분해**: Divide & Conquer, 하향식 전략.
* **패턴인식/추상화**: 핵심 구조 인식 및 단순화.
* **알고리즘/자동화**: 절차화 및 프로그래밍 구현.
* **도구 및 언어**: 스크래치, 엔트리, 파이썬 등 교육용 언어 활용.


## [**8장 – 프로그래밍언어**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.08)

* **개념**: 저급언어(기계/어셈블리), 고급언어(C, Java 등).
* **세대별 분류**: FORTRAN, COBOL → BASIC, C++ → 파이썬, R 등.
* **개발환경**: 컴파일러, 디버거, IDE(비주얼 스튜디오 등).
* **구현과정**: 컴파일 → 링크 → 실행파일 생성 → 디버깅.
* **주요 언어**: 포트란, 코볼, 자바, 파이썬, 고, 스위프트 등.
* **OOP(객체지향)**: 추상화, 상속, 캡슐화, 다형성.


## [**9장 – 데이터베이스**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.09)

* **개념**: 데이터 중복 최소화, 통합 저장소.
* **DBMS**: 사용자와 DB 연결, 저장/질의/접근 인터페이스 제공.
* **구조**: 필드 → 레코드 → 파일 → 데이터베이스.
* **추상화 단계**: 물리/논리/뷰, 스키마 설계.
* **모델**: 계층형, 네트워크형, 관계형(테이블 기반).
* **SQL 실습**: 테이블 생성, 데이터 삽입·조회.
* **DBMS 종류**: MySQL, Oracle, SQLite 등.
* **데이터마이닝/NoSQL**: 패턴 추출, 비정형 데이터 처리(MongoDB 등).


## [**10장 – 네트워크와 WWW**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.10)

* **개념**: 송수신자, 매체, 프로토콜(TCP/IP 등), LAN/WAN 구조.
* **장치**: 모뎀, NIC, 허브, 라우터, 게이트웨이 등.
* **분류**: LAN, MAN, WAN (이더넷 등 표준 포함).
* **운영 설정**: IP 주소, DNS, tracert 등 명령어.
* **인터넷 역사**: ARPANET → IPv4/IPv6, 도메인 구조.
* **WWW 구성**: 클라이언트-서버, HTML5, JavaScript 기반.
* **웹 패러다임**: 웹1.0(정적), 웹2.0(참여), 웹3.0(스마트/시맨틱).


## [**11장 – 제4차 산업혁명과 첨단기술**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.11)

* **산업혁명 역사**: 증기 → 전기 → 디지털 → 스마트혁명.
* **핵심기술**: AI, IoT, 빅데이터, 클라우드, 로봇, 블록체인 등.
* **초연결사회**: 정보 생성·공유·활용이 네트워크 기반으로 통합.
* **모바일/클라우드**: 스마트폰, 앱스토어, SaaS 등 서비스 모델.
* **지능형로봇**: 센싱+동작, 자율로봇, 웨어러블.
* **빅데이터**: 3V(양, 속도, 다양성), 산업 적용 사례 다수.
* **블록체인/암호화폐**: 분산 원장, 비트코인, 스마트 계약 응용.
* **미래 역량**: 자기주도학습, 창의성, 융합력, 소통.
* **교육 대응**: 마이크로칼리지, 나노디그리, 단기 집중 교육.


## [**12장 – 멀티미디어 개론**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.12)

* **개요**: 오디오, 이미지, 영상 등 통합 표현 미디어.
* **데이터 형식**: MP3, JPEG, MPEG, ASCII 등.
* **시스템 구성**: 하드웨어(그래픽카드 등), 소프트웨어(포토샵 등).
* **데이터 처리/압축**: 무손실 vs 손실 압축, Huffman, JPEG.
* **응용분야**: VOD, 원격진료, 게임, UHD.
* **보안**: 워터마킹, DRM, 핑거프린팅으로 저작권 보호.


## [**13장 – 정보보안**](https://github.com/LutetiumCalciumLee/Studying_Computer_Science/tree/Ch.13)

* **개념**: 시스템/네트워크 보호, 정보 위협(가로채기, 위조 등).
* **보안 목표**: 비밀성, 무결성, 가용성 + 인증, 접근제어.
* **위협**: 바이러스, 피싱, 랜섬웨어, 해킹, DDoS 등.
* **보안수칙**: 업데이트, 백신, 강한 비밀번호, 백업.
* **암호화기술**: 대칭/비대칭키, RSA, AES, 전자서명.
* **인터넷보안**: 방화벽, SSL, 이메일/웹 보안.
* **정보윤리**: 책임, 존중, 정의 원칙. 개인정보·저작권 보호 강조.
